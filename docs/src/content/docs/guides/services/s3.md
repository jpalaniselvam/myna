title: S3

`myna` supports common S3 operations for managing buckets and objects.

## Supported Kinds

*   `s3.list_buckets`
*   `s3.list_objects`
*   `s3.put_object`
*   `s3.get_object`
*   `s3.delete_object`

## Buckets

### List Buckets (`s3.list_buckets`)

Returns a list of all buckets owned by the authenticated sender.

#### Example

```toml
version = "1.0"
kind = "s3.list_buckets"
description = "List all my buckets"
```

## Objects

### List Objects (`s3.list_objects`)

Lists keys in a bucket. Uses `ListObjectsV2` API.

#### Configuration (`[s3]`)

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `bucket` | string | **Yes** | The name of the bucket. |
| `prefix` | string | No | Limits the response to keys that begin with the specified prefix. |
| `max_keys` | int | No | Sets the maximum number of keys returned in the response. |

#### Example

```toml
version = "1.0"
kind = "s3.list_objects"

[s3]
bucket = "my-bucket"
prefix = "logs/"
max_keys = 50
```

### Put Object (`s3.put_object`)

Uploads an object to a bucket.

#### Configuration (`[s3]`)

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `bucket` | string | **Yes** | The name of the bucket. |
| `key` | string | **Yes** | The object key. |
| `content_type` | string | No | A standard MIME type describing the format of the contents. |
| `metadata` | map | No | A map of metadata to store with the object. |

The content to upload is taken from the `[payload]` block (either `data` or `file`).

#### Example

```toml
version = "1.0"
kind = "s3.put_object"

[s3]
bucket = "my-bucket"
key = "configs/app-config.json"
content_type = "application/json"
metadata = { "environment" = "production" }

[payload]
data = """
{
  "setting": "value"
}
"""
```
